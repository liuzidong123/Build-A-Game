# 成语动图猜猜猜 · 15 分钟积分赛

看图拼成语：每道题把一个四字成语拆成 4 个**随机抽选 + 随机动效**的图块（字面或谐音），
猜中 +1 分，猜错 -1 分，15 分钟倒计时结束按分数排名。

## 运行

```powershell
# 方式一：直接双击 index.html（纯静态、无依赖、可离线）
# 方式二：本地起静态服务（手机同网段可访问）
python -m http.server 8765 --bind 0.0.0.0
# 浏览器打开 http://127.0.0.1:8765/
```

产物路径：`apps/games/idiom-anim/`（项目未约定游戏目录，按 `apps/` 现有子项目惯例新建）。

## 产品定义（基线 v0.1.0）

| 项 | 内容 |
| --- | --- |
| 玩家 / 幻想 | 中文玩家或亲子场景；「看几个会动的小图标，把成语念出来」的解谜快感 |
| 核心动词 | 看图 → 念字 → 输入 → 立即得到对/错反馈 |
| 首局目标 | 30 秒内理解规则并答对第一题 |
| 平台 / 输入 | 默认 H5 手机网页；竖屏单手触控 + 输入法；桌面浏览器同样可用 |
| 质量档位 | 原型可玩的完整垂直切片（非正式发行） |
| 范围 | 单机 15 分钟一局、逐字动图、±1 计分、连对统计、本地排行榜、暂停/提前结束 |
| 非范围 | 联机/账号/云排行榜、付费、广告、排行榜分享图片、成语释义百科 |
| 预算 / 性能 | 单页 < 100 KB 文本资源（实际约 45 KB），首屏无网络请求，动效只用 CSS transform/opacity |
| 验收阈值 | 见下方验收表 A1–A10 |

**假设（未另行追问，依据用户原话与 Skill 默认）**

1. 用户未指定平台 → 按 Skill 默认做 H5 手机网页，交付 `index.html`。
2. 「动图」采用**程序化动效图块**（emoji 字形 + 7 种随机 CSS 动效 + 随机延迟），不引入 GIF 二进制、不依赖外网；理由：Skill 资源优先级为「既有资产 → 程序化 → 授权资源 → AI 生成」，且需离线可跑。`data.js` 中候选若填 `.gif/.png/.webp/.svg` 路径，图块会自动改用 `<img>` 渲染，便于后续替换成真 GIF。
3. 「排行榜」为**本机浏览器排行榜**（localStorage），多人依次在同一台设备上玩、按分数决胜；未获授权接入服务端，故不做联机。
4. 15 分钟、+1/-1 的语义按用户原话实现；分数允许为负。

## 玩法与规则

- 对局时长固定 `900s`，由 `logic.js: ROUND_SECONDS` 定义；倒计时归零自动结算，未答的题不额外扣分。
- 单题：4 个图块顺序对应成语四个字；同一题可反复猜，**每次猜错都 -1**；「看答案」同样 -1 并进入下一题。
- 答对 +1，连对计数递增（答错或看答案清零），最高连对进入结算页。
- 抽题：整库洗牌后逐张取，取完再洗；跨轮保证不出现「上一题 == 下一题」。
- 暂停会冻结倒计时（切后台自动暂停），避免挂机刷分或计时不公平。
- 排行榜排序：分数降序 → 答对题数降序 → 达成时间升序；最多保留 50 条，页面展示前 10。
- 结算页可重复进入，但「提交成绩」每局只允许一次（按钮置灰）。

## 技术与文件

| 文件 | 职责 |
| --- | --- |
| `index.html` | 三个界面（开始 / 对局 / 结算）+ 暂停遮罩、toast、礼花 canvas |
| `style.css` | 深色霓虹视觉、7 组图块动效、手机竖屏布局、`prefers-reduced-motion` 降级 |
| `data.js` | 76 条成语题库：`{w: 成语, h: [4 组图块候选], n: [4 条释义/谐音标注]}` |
| `logic.js` | 纯逻辑：归一化、判分、抽题、计时格式、排行榜排序（无 DOM，可被 node 直接测） |
| `game.js` | 界面控制：渲染、输入/IME、计时、暂停、结算、localStorage 读写、礼花 |
| `tests/logic.test.cjs` | 23 项逻辑回归 |
| `tests/ui.smoke.cjs` | 极简 DOM 桩下的 12 项界面流程冒烟 |

- 纯静态、零第三方依赖、零网络请求；脚本为传统 `<script>`（非 ES module），`file://` 直接打开也可运行。
- 存储键：`idiom-anim.board.v1`（成绩数组）、`idiom-anim.name.v1`（上次昵称）。

## 已知限制

- emoji 字形由系统字体决定，旧版 Windows 10 上部分新 emoji（🪨🪵🪶🪡）可能显示为方框；换用图片路径即可规避。
- 排行榜仅存本机浏览器，清缓存即丢失；无跨设备同步。
- 无拼音/模糊匹配，答案必须四字完全正确（会忽略空格与标点）。
